# 🥗 Nutrition App

## 📌 Project Description

Nutrition App is a React application that allows users to search for ingredients and get detailed nutrition information using the API Ninjas Nutrition API.

The app helps users analyze food ingredients by entering a keyword and displays nutritional information including carbohydrates, fats, fiber, sugar,  and other nutrition facts.

The main focus of this project was practicing React Hooks, working with API requests, asynchronous functions, loading states, error handling, and displaying dynamic data.

## ⚙️ Installation

To run this project locally, follow these steps:

```bash
git clone https://github.com/OlgaVetrov/NutritionApp.git
```

```bash
cd NutritionApp
```

```bash
npm install
```

```bash
npm run dev
```

After running the command, the application will open in your browser.

## 🚀 Usage

🥗 Nutrition App helps users quickly check nutritional information about different ingredients.

Users can enter an ingredient name and explore detailed nutrition facts retrieved from the API.

✨ What you can do:

- 🔍 Search ingredients by keyword

- 📊 View detailed nutrition information

- 🥑 Explore different nutrient values

- 🌱 Analyze food ingredients

- ⚡ Get instant results from API requests

- ❌ Receive error messages for invalid ingredients

## ⭐ Main Feature

The main idea of this project is dynamic nutrition analysis.

The application uses React state management and API requests to fetch nutrition information based on user input. The data is displayed dynamically, allowing users to analyze ingredients without reloading the page.

This project helped practice working with external APIs, asynchronous functions, React Hooks, conditional rendering, and handling loading and error states.
